# Sajidur Rahman Portfolio / Resume

This repository contains a single-page personal portfolio and resume website for Sajidur Rahman, built with HTML and Tailwind CSS.

## Files

- `sajidur_rahman_cs_oct_1_2026.html` — main portfolio/resume page

## Preview locally

Because this is a static site, you can preview it by opening the HTML file directly in a browser or by serving the folder locally.

### Option 1: Open directly

- Open `sajidur_rahman_cs_oct_1_2026.html` in your browser.

### Option 2: Local web server

From the project directory, run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000/
```

## Customize content

Edit the content in `sajidur_rahman_cs_oct_1_2026.html` to update:

- profile summary
- education and experience
- skills and research
- contact links
- theme and styling

## Deployment

This site can be hosted on GitHub Pages or any static hosting provider.

For GitHub Pages:

1. Push this repository to GitHub.
2. Enable GitHub Pages in the repository settings.
3. Select the main branch as the publishing source, or use a docs folder if preferred.
4. Access the deployed site via the GitHub Pages URL.

## Notes

- The site uses a CDN-hosted Tailwind CSS script and Google Fonts.
- It includes light/dark theme toggling, print styling, and search/filter functionality for resume sections.
